# Engram V1 — Context Engine

V1 is the **substrate**: structured engineering context, hybrid retrieval, provenance, and preflight packets.

Not included in V1: full agent router, learned routing policies, governance runtime in CI.

**Live demo:** [https://engram-cjph.onrender.com/try](https://engram-cjph.onrender.com/try) · [`HOSTED_TRY.md`](./HOSTED_TRY.md)

## Prerequisites

- Python 3.11+
- Docker is **optional**. Default store is local (file-backed graph + embedded Qdrant).

## Quick start (no Docker)

```bash
cp .env.example .env
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

python main.py seed
python main.py serve
```

Open `http://127.0.0.1:8000/docs` or `http://127.0.0.1:8000/try`

## Optional: Neo4j + Qdrant via Docker

Install [Docker Desktop](https://docs.docker.com/desktop/setup/install/mac-install/), then:

```bash
# in .env
ENGRAM_STORE=docker

docker compose up -d
python main.py seed
python main.py serve
```

## Endpoints

| Method | Path | Purpose |
|---|---|---|
| GET | `/health` | Graph + vector connectivity |
| GET | `/meta` | Version, public_mode, capabilities |
| GET | `/try` | Try UI (redirect) |
| POST | `/ingest/sample` | Reload demo org into graph + vectors |
| POST | `/ingest/github` | JSON: repo, optional service/limit/token (additive; token ignored in public mode) |
| POST | `/preflight` | Evidence-backed preflight packet |
| POST | `/query` | Grounded context retrieval |

## Example: preflight

```bash
python main.py preflight \
  --service "Auth Service" \
  --task "Increase auth session TTL from 24 hours to 7 days"
```

Or via API:

```bash
curl -s http://127.0.0.1:8000/preflight \
  -H 'Content-Type: application/json' \
  -d '{
    "service": "Auth Service",
    "task": "Increase auth session TTL from 24 hours to 7 days"
  }' | jq
```

Expected: `risk_level` medium/medium-high, `policy_outcome` review/warn, evidence citing INC-* / ADR-* / PR-*.

## GitHub PRs (additive)

Does **not** clear the sample org. Pull requests (paginated, up to 200), plus recent commits if the repo has no PRs.

```bash
python main.py ingest-github --repo anthropics/claude-cookbooks --limit 30
# optional: --token ghp_...
```

Optional `GITHUB_TOKEN` in `.env` for private repos and higher rate limits. The try UI can pass a one-shot token only in local/dev (not public mode).

### Try UI

```bash
python main.py serve
```

Open **`http://127.0.0.1:8000/try`**.

1. **Your GitHub** — ingest → query / preflight → optional **run on clone** (local/dev; worktree; no merge)
2. **Sample Auth risk loop** — seed → run → reject/approve → run again (priors)

`/health` should report version **≥ 0.4.0**. Local ingest reuses the API process’s Qdrant client (do not open a second embedded client on the same path).

Honest split:

- **Your GitHub** → real PR/commit context for query + preflight
- **Sample Auth org** (`python main.py seed` + `run`) → ADR/incident risk gate and agent worktrees
- Hosted public mode is a tight demo, not multi-tenant SaaS

## Architecture (V1)

```text
Sample JSON / GitHub PRs
        ↓
   Ingestion (seed / github)
        ↓
 Neo4j or local graph + Qdrant Vectors
        ↓
 Hybrid Retriever (graph neighborhood + vector search)
        ↓
 LangGraph preflight workflow
        ↓
 Rule-based risk + policy outcome
        ↓
 PreflightPacket (evidence-linked)
```

## Embeddings

- With `OPENAI_API_KEY`: OpenAI `text-embedding-3-small`
- Without: deterministic local hash embeddings (dev/demo only)

Re-seed after switching embedding backends (`python main.py seed`).
