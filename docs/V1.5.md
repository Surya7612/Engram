# Engram V1.5 — Context Router + eval harness

V1.5 decides **which context to load for this task**, then measures that against fixed baselines.

Not included: agent router, learned policies (V3).

## What it adds

- Deterministic **context router** (`engram/routing/context.py`)
  - `docs` → narrow
  - `incident` → failures + recent PRs
  - `risk_sensitive` (auth/TTL/cache) → incidents + ADRs + PRs + one-hop dep incidents
- Retrieval modes: `adaptive`, `hybrid`, `vector`, `graph`, `huge`
- Eval set: `data/evals/v1.5_cases.json` (modes are meant to disagree on some cases)
- LangSmith tracing when `LANGCHAIN_TRACING_V2=true`

## Run evals

```bash
python main.py eval
python main.py eval --json
```

Compare modes on:

- required-evidence recall
- wasted artifacts (easy tasks should not pull auth incident history)
- token estimate
- groundedness: cited ADR/INC/PR/COMMIT ids must appear in retrieved evidence
- abstention: evidence present but the answer cites nothing
- hallucination risk: unsupported citations / citations

If `OPENAI_API_KEY` is set, adaptive answers are generated by the model and then checked. Without a key, answers are the evidence list.

LangSmith: eval summary is logged when `LANGCHAIN_TRACING_V2=true`. This is a run record, not a hosted experiment leaderboard.

Preflight with a mode:

```bash
python main.py preflight --mode adaptive
python main.py preflight --mode huge
```

API: `POST /eval`

## Honest bar

This eval set is a small demo org, not a published result. A routing win here means modes disagree (vector misses a graph ADR, graph misses a dep-only incident, huge wastes payment TTL lookalikes)—not that the policy generalizes.

Groundedness is a **lexical citation check**, not an NLI hallucination paper. Abstaining with evidence in context is not a 1.0.
