Guide

What each step is for

Engram is a control plane around coding agents—not a chatbot over your repo. Prefer /try on this host.

1 · Connect Aim: load public GitHub into the context substrate. Ingest fetches PRs (or commits) and writes them into the graph + vectors as a named service. No clone, no merge. 2 · Ask Aim: see task-specific context with provenance. Query answers from retrieved evidence. Preflight builds a risk/policy packet (what matters before anyone edits code). 2b · Run on clone Aim: candidate change in a disposable worktree. Local/dev only on the public demo. Thin without ADRs—use section 3 for the full gate story. 3 · Sample Auth Aim: risk routing + human governance. Run agents hits ADR-12 (TTL cap) → usually block. Reject records a prior; run again to see learning-layer lookup (not a trained policy).
